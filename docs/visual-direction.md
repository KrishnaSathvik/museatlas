# Muse Explained visual library

Keep Syne headings and IBM Plex Sans body copy. Palette: paper #ffffff, canvas #f7f8fa, ink #111111, muted #555b65, action blue #0668e1. Blue identifies an action, a selected element or the focal result.

Overview orients with one featured story. Explore owns the only full family map. Product pages use media suited to the subject: computational workflow, local hardware, editor, image workbench, transcript, or video timeline. Sources, safety information, walkthrough steps and use-case previews remain visible without clicks or hover.

All generated imagery is conceptual editorial illustration, never presented as a real Muse screenshot or an output generated by Muse. Example thumbnails use authentic screenshots from the original recipes. Where no application screenshot exists (GitHub Automation and local Glimmer code review), the actual recipe page is captured and explicitly labeled. Provenance is recorded in example-screenshots.json.

The exact master prompt and 29 individual generation prompts are in visual-assets.json. Generate each asset separately with the built-in image tool; persist outputs under public/illustrations.

## Delivery and verification

All 29 assets were generated with the built-in ChatGPT image tool, visually reviewed and saved in public/illustrations. Next Image serves responsive sizes. The manifest records the exact subject prompts and original generated paths.

The family map, shared hosted/local architecture and ten example architectures are generated diagram images under public/diagrams; their generation records are in generated-diagrams.json. Captions, technologies and product-role descriptions remain accessible HTML. Sources render inline. All walkthroughs are illustrative rather than live model calls.

The expanded-content browser review covers 25 routes at desktop and phone sizes, image decoding, overflow, all walkthrough steps, inline safety and sources, authentic example thumbnails and gallery filtering. Review screenshots and results are saved under output/review/expanded.
